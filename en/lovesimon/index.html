Love, Simon

Love, Simon – Production Design Study

ClientAcademic project
Production TypeProduction design based on screenplay analysis
Overview

Complete production design development for the film Love, Simon, created from screenplay analysis without reference to the original film.

The project involved building the full visual world of the story, including sets, color palette, costume concepts and scenic design.

Concept & Art Direction
  • Development of the film’s visual concept
  • Creation of a color script to guide visual storytelling
  • Research and visual references for the narrative universe
Scenic Design
  • Set design for each location described in the script
  • Environmental storytelling through set dressing and props
  • Development of scenic elements supporting the narrative
Visual Design
  • Color palette development for environments and characters
  • Costume concepts aligned with the story’s visual tone
  • Atmosphere design for each location
Technical Development
  • Scenic floor plans
  • 3D modeling of sets
  • Physical and digital set maquettes
  • Development of a complete art department bible
OutcomeA fully developed production design proposal integrating narrative, color, set design and visual storytelling.
